# MAXWELL OBS tracker

An obs script that captures Animal Well in portrait (1080x1920) using a built in maxwell cheat so that I can make youtube shorts easily lol.

## Setup

1. Turn on **Portrait capture tracker** in MAXWELL -> settings.
2. Make a `1080x1920` scene in OBS.
3. Add a game capture named `Animal Well`.
4. Open **Tools > Scripts** and add `maxwell_portrait_tracker.py`.
